# Лабораторная работа по теории вероятности №2

Выполнял - Хасанов Дмитрий Вадимович M3239

Хасанов Дмитрий. Х, А, Д, М — 23, 1, 5 и 14 буквы в кириллице соответственно. Номера вариантов:

    — (23 % 3) + 1 = 3
    — (5 % 4) + 1 = 2
    — (1 % 5) + 1 = 2
    — (14 % 4) + 1 = 3

# Структура проекта

Под каждое задание есть папка, в которой представлено аналитическое решение в виде фотографии и код алгоритма симуляции с таблицами результатов (при условии, что в задании это требовалось).

Также в корне репозитория будет лежать .pdf файл, в котором будут собраны все аналитические решения и коды переборов.
